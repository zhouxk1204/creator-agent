# 鸟的出租车

![[封面/938/938_1_4k.jpg]]

周日早上，大雄约好要和静香出去玩，结果却睡过头了，顿时慌了神！他拜托哆啦 A 梦拿出“竹蜻蜓”或“任意门”，但对方却说这两样道具都送去维修了。
“如果能变成鸟立刻就能飞走就好了……"听到大雄的话，哆啦 A 梦说正好有个好东西，便拿出了“鸟的出租车”。据说只要使用它，就会有鸟把你带到目的地。
果然，一只捕捉到“鸟的出租车”信号的鸽子飞进了房间。大雄向鸽子说明目的地并喂了它一些食物后，自己的身体突然发出光芒变小，瞬间移动到了鸽子的背上，把他吓了一跳！
转眼间，大雄就到达了目的地的车站，并与静香会合。然而，静香突然想起钢琴课的时间改到了今天上午，而且她还得去取一次乐器。
就在这时，哆啦 A 梦正好骑着麻雀的“鸟的出租车”赶到了，于是静香也决定叫一辆“鸟的出租车”……！？
